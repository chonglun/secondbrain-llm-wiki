## 一、這本書在講什麼

- **核心主張**：管理的本質是「**整合**」；而所有與管理有關的「道理」，本質上都是一連串的**因果關係或配合關係**，都可以用流程圖表示。（頁1、頁2、頁32）
- **管理矩陣**就是試圖把這些散落、千變萬化的「因果關係流程圖」整合成一個**近乎標準化、周延而互斥的架構（編碼系統）**。（頁36、頁37）
- 它的定位很明確：「管理矩陣充其量只能『**解說**道理』，但不負責『**創造**道理』。」其價值在於協助**歸納、活化、累積、記憶**各種因果關係與現象。（頁44）
- 全書分**四個部分**（頁4）：
  1. 管理的意義 → 把「整合」視為管理的核心。
  2. 用「整合的標的 × 整合的對象」建構 6×6 矩陣，再加「陰陽兩面」＝**72 欄**。
  3. 詳細說明 72 欄的內容與定義。
  4. 用 70 則實例（13 類例題）示範如何用管理矩陣解析管理現象。

> [!note] 工具的用途（頁2、頁3）
> 作者列出管理矩陣的價值：建立有系統的知識儲存／歸類；提升活學活用與聯想效率；整合各種「一偏之見」形成更完整論述；協助決策與行動更周延，行動未達標時也能回到矩陣找原因。

## 二、第一部分：管理的核心意義是「整合」

### 1. 組織與管理的起源（頁7、頁8）
- 人類求生存需要合作；較長期、有規模、穩定有效率的合作需要「**合作系統**」（cooperative system, Barnard 1938）。
- 合作系統包括「**組織**」與「**交易市場**」。企業、家庭、國家、社團、股票市場等都是合作系統。
- 任何合作系統都需要有人去「**創建、維持、發展**」，這就是領導者／高階管理的功能。
- **「管理」（組織的創建、維持與發展）的核心本質，可簡稱為「整合」。**

### 2. 整合的內涵（頁9）
結合各方資源與努力，經由合作創造價值，達到各方目的。高階領導者的具體任務包括：設定共同方向、組織目標與個人目標的妥協共創多贏、共同解決問題／創造價值、資源取得與配置、資訊掌握與影響力運作、內外行動的協調、以及對所有「投入者」的成果分配。

### 3. 整合的三要素：主體、對象、標的（頁10、頁17）
- 整合有「**主體**」（整合者）、「**對象**」（被整合者）與「**標的**」。
- **人人都可以是整合者，也都可能是被整合者。**「待價而沽」就是選擇想被誰整合；成為被整合的潛在對象，表示自己具有被看重的價值。（頁22）
- **整合的對象**：從宏觀（外界機構與其中個人）到微觀（組織內部各層級每一個人）。
- **整合的標的**：即「六大管理元素：目環決流能資」。

### 4. 從「個人元素」到「六大管理元素」（頁11、頁12）
人的特性可用「**四大個人元素**」描繪，開始「行動」後再加兩項，合稱「六大個人元素」：
- 價值觀念／人生目標 → **目標與價值前提**
- 對事物（含自己）的認知 → **環境認知與事實前提**
- 知能（因果理解、技巧方法、體能） → **知識與能力**
- 有形與無形資源（財貨土地 vs 社會關係聲望） → **資源**
- （行動時新增）**工作流程**、**決策**

> 四大個人元素也是「人際交往」的基礎：價值觀相近者互相吸引，不同者互相排斥；交友常因彼此「四大」互補而得增益；有人飽和於「四大」反而少友。（頁12）

## 三、六大管理元素（目環決流能資）詳解（頁13）

| 元素 | 簡稱 | 內涵 |
|---|---|---|
| 目標與價值前提 | **目** | 價值觀、人生／工作目標、文化、風險偏好、心理需求的優先順序。各種「目」的衝突與妥協是人世間重要課題。 |
| 環境認知與事實前提 | **環** | 基於接收資訊、親身體會、觀察記憶所產生對事物的信念與認知。 |
| 決策與行動 | **決** | 依前述兩種「前提」所做的各種決策與行動。 |
| 創價流程 | **流** | 營運流程＋管理流程，含溝通、決策、行動流程。 |
| 知識與能力 | **能** | 知識、方法、技巧、體能、對因果關係的掌握；也可代表知能的載具——「人」。 |
| 有形與無形資源 | **資** | 金錢、工具、土地，到形象、社會關係、社會地位；個人的「時間」甚至「外貌」也屬無形資源。 |

> [!note] 「前提」二字的由來（頁14）
> 取自 Simon（1947）的 factual premises and value premises。決策者的「價值觀念」與「對事實的認知」決定其決策方向——這是「目」與「環」被稱為「前提」的原因，也是對前輩學者原創觀念的致敬。

### 概念釐清
- **「環境認知」≠「外界環境」**（頁15）：前者是經感知、學習、調研、他人告知所產生的「了解與信念」；後者指政治、經濟、文化、消費者偏好、競爭者等客觀狀態。
- **存量 vs 流量**（頁17）：六大元素皆有「現狀（存量）」與「變化（流量，含方向與速度）」。
- 其中「**決**」與「**流**」主要與「組織」有關；其餘四者（目環能資）既屬組織也是原本的個人元素——成員憑個人的「目環能資」加入組織。（頁17）

### 六大元素就是 give-and-take 的標的（頁18-21）
作者以組織與成員的整合關係逐項舉例（節錄）：
- **目**：組織以理念與協助達成員工人生目標來吸引人，以任務目標引導努力方向；員工以品德、認同、忠誠換取肯定。
- **環**：組織以形象吸引顧客員工；員工因擁有足量正確資訊而有好表現。
- **決**：許多管理作為就是要讓員工「做出正確決策、採取合於組織期待的行動」；行銷的目的是讓顧客做出有利本組織的採購決策。
- **流**：產銷、物流金流資訊流的銜接配合，其標的都是「流程」。
- **能**：組織在意員工知能，員工從組織獲得的很大一部分是「知能成長」。
- **資**：員工要薪酬獎金（有形）與職稱地位人脈（無形）；投資者的 give-and-take 是股金與股息。
- 結論：**六大管理元素既是整合的「標的」，也是整合的「工具」。**

> 整合無所不在：創業、人力資源、行銷、財務、供應鏈、經營策略，全都是整合。（頁22-24）

## 四、整合的對象：六大層級（頁25、頁26）

從個人到世界，簡化為六個層級，以數字 1–6 表示（縱軸）：

| 編號 | 層級 | 說明 |
|---|---|---|
| **1** | 總體環境 | 世界上的人類與萬物；其決策者簡稱「遊戲規則的制定者」。 |
| **2** | 任務環境 | 組織的上下游交易、合作、競爭對象（≈ 產業）。 |
| **3** | 組織平台 | 即本組織。其六大元素「不等同」於機構領導的六大。 |
| **4** | 機構領導 | 可能不只一人。 |
| **5** | 各級管理 | 通常不只一層；落實上級目標、協助基層創價。 |
| **6** | 基層成員 | 直接「創造價值」的執行者（醫師、教授到作業員）。 |

- 實務階層很多，可用 **4.8、5.1、5.2** 等表示不同級別；家族企業準接班人可用 **4.2** 之類表示。（頁38、頁52）
- **每一層級都有自己的「目環決流能資」**。組織平台（3）擁有「屬於組織但不屬於任何個人」的六大元素。（頁26）
- 管理矩陣**不從某一特定層級的立場出發**——從總體環境到基層人員，都可能是整合主體，也可能是被整合對象。（頁26）

> [!note] 軸線與節點（頁27、頁28）
> 「六大」經由「**軸線**」在層級間上下流動，軸線分「**主軸**（直接創價，如產銷）」與「**輔軸**（人資、財會、資訊、法務、稽核等幕僚）」。各級主管是六大流動的「**節點**」。層級太多或節點扭曲，會導致「六大」無法足量、正確地傳達到基層——這是組織設計的關鍵考量，也是後面「軸線失靈」議題的根。

## 五、第二部分：管理矩陣的建構

### 1. 為什麼要矩陣（頁32-36）
- 所有「道理」都是因果關係或配合關係，可用流程圖呈現；圖像思考有助理解、記憶、溝通、主持討論時的提問與歸納。
- 但個別流程圖牽涉因素千變萬化、彼此整合不易。管理矩陣用一個**周延而互斥**的標準架構，把這些流程圖有系統地收納。**「我們在腦中記得此一架構，就能輕鬆理解、產生、記憶各種因果關係流程圖。」**

### 2. 兩大構面與編碼（頁38）
- **縱軸**＝整合的對象（6 層級，1–6）。
- **橫軸**＝整合的標的（六大管理元素，目環決流能資）。
- 每一欄位以「元素＋層級」編碼：**「目4」＝機構領導者的目標與價值觀念**；**「能5」＝某層級單位管理人員（或其單位）的知能**；餘類推。
- 6×6 ＝ 36 欄。

### 3. 陰陽兩面 → 72 欄（頁39-43，重點章節）
- 六大元素皆有**陰陽兩面**，36 欄 × 陰陽 ＝ **72 欄**。作者視「陰陽兩面具體落實在 36 欄中」為管理矩陣的**重要創新與貢獻之一**。
- **陽**＝與「**正式組織／正式體制**」有關者；**陰**＝「**屬於個人**」或「**非正式的溝通與行動**」有關者。
- **陰陽不分善惡**，管理上更應重視兩者互補相成。從組織立場「以陰害陽」不宜，但「人人終究是為自己」屬常態。
- 真實世界通常「**陰面比重較大**」，像海面下的冰山；結合眾人之力形成正式合作系統後，才出現「陽面」。
- **轉陰為陽 / 轉陽為陰**（核心動態，整理）：
  - 領導者的整合工作，大部分是號召、鼓勵、要求大家「**轉陰為陽**」（把個人的知能、資源、目標貢獻給組織）。
  - 把組織所擁有的（產品、收益、知能、見聞、社會關係）依制度合理分配回各人之陰面，是正常的「**轉陽為陰**」。
  - 任何元素「全陽」或「全陰」皆不正常；未進組織前、離職後，個人只擁有陰面元素。
  - 個人一生職涯可謂「**由陰而陽再回歸於陰**」，故以自己的陰面為主體。
- **傳統管理教育的盲點**（頁43）：高度重視「陽面」，很少觸及「陰面」（人性、非正式組織、非正式溝通、形象與關係、個人/組織目標衝突、察言觀色、利益交換）。導致只憑「陽面」知識的年輕 MBA，適應組織時反而不如有觀察模仿經驗者。
- **AI 含意**（頁42，作者前瞻觀點）：「將來 AI 所能替代者，大部分是**陽面**的工作。高階領導者的角色，其實主要都是難以轉變為陽面的『**陰面**』元素」——如對幹部內心「目」「環」的掌握、對外關係、組織文化、非正式凝聚向心力。

### 4. 「爬格子」與七十二欄的關聯（頁44-46、頁54）
- **爬格子**：想深入理解任何現象背後的「道理／因果關係／本質」時，試著逐一對照各欄位去想道理。常「爬格子」可訓練思考力與記憶。
- 72 欄＋欄位間的互相影響，構成管理理論與現象的「**零組件**」；大部分管理理論與組織內外現象都可「拆解」成這些零組件，也能反向組合成各種道理、建議、理論。
- 72 欄大致已包含各種管理議題的「**考慮因素**」，是各級管理者應「**時時在觀照中**」的觀念架構。（頁54、結語）

## 六、第三部分：72 欄位的內容與定義（頁56-75）

**排序原則**（頁56）：先依六大元素分類 → 每元素內依層級 1→6 由上而下 → 同層級內「先陽後陰」。作者註明此為原創寫作，定義「尚在力求完善中」，且含部分主觀成分。

以下為各元素定義的**精簡整理**（陽＝正式／組織面，陰＝個人／非正式面）：

### 目（目標與價值前提）（頁57-58）
- **目1**：陽＝世人追求的安和樂利、永續繁衍等普世價值；陰＝規則制定者對自身利益、權力的追求。
- **目2**：陽＝任務環境各機構的機構目標與對本組織的期待；陰＝其個人利益權力追求（個人消費者/投資者只有陰面目2，如產品偏好、價格敏感度、風險偏好）。
- **目3**：陽＝組織目標與文化（永續、獲利、成長、使命、和諧）；陰＝未見諸書面的組織文化、權力距離。
- **目4/目5/目6**：陽＝為達上級目標而設定的（領導者/各級管理/基層）工作目標；陰＝其本人的人生目標、價值觀、信念、心理需求、品德與判斷是非的標準。

### 環（環境認知與事實前提）（頁59-60）
- 各層級皆然：**陽**＝經「正式管道、資料庫、檔案」所獲得的資訊與認知；**陰**＝經「非正式管道」所獲得的認知。涵蓋對六大層級各種「目環決流能資」的認知。

### 決（決策與行動）（頁61-62）
- **決1**：陽＝規則制定者基於理性的決策、政策、治理（貿易、環保、戰爭、合約規範）；陰＝基於陰面目1的決策，及廣大世人自行的決策行動。
- **決2**：陽/陰＝任務環境機構或個人基於理性程序 / 基於陰面目2或非正式程序的決策。
- **決3**：陽＝組織基於陽面目3的書面決策政策（含「決策存量」如書面規定）；陰＝不成文規定、慣例。
- **決4/決5/決6**：陽＝（領導者/各級管理/基層）在職掌與授權範圍內的所有決策行動；**陰**＝基於其陰面目，願意把「人生的多少比重」放在這個組織（心力、時間投入，甚至去留）。

### 流（營運流程與管理流程）（頁63-68）
- 每層級皆分**營運流程**（實際創價活動，如採購→研發→製造→銷售）與**管理流程**（規劃、溝通、協調、要求、考核獎懲）。
- **流1**：世界層次的產業加值與世界秩序（陰面含地下經濟、非正式互信互惠機制）。
- **流2**：產業鏈與協力產業的競合、金物資訊人流（陰面＝地下經濟、私交、小道消息流傳）。
- **流3**：本組織從投入到產出的整體創價流程；原則上「流3 ≈ 其下流4＋流5＋流6 的總和」，可逐級劃分。
- **流4/流5/流6**：上一級流程中劃歸該層級職掌（「責任區」「管區」）的部分。**職位愈高，管理流程比重愈大、陰面（彈性）也愈高**；基層（作業員、品檢、警衛）愈應「依規定」，陰面比重低。把規範外但合理的做法「制度化」＝「流程的轉陰為陽」。

### 能（知識與能力）（頁69-71）
- 各層級：**陽**＝該主體（人/單位）的知能、科技、人才，已納入對應「陽面流」並充分發揮者；**陰**＝尚未納入、尚待開發發揮的潛在知能（如「野有遺賢」、員工未被發現的潛能）。「能」也代表知能的載具——「人」。

### 資（有形與無形資源）（頁72-75）
- 各層級：**陽**＝已納入對應「陽面流」、為創價貢獻的有形資源（土地、設備、資金、產品成品）與無形資源（品牌、形象、聲譽、智財權、社會關係）；**陰**＝閒置／未充分利用的資財，或個人/家族擁有的財富、聲望、人脈、時間、儀表容貌。
- 重要細節：產品成品＝陽面資3（可與客戶的資2交換）；未分配利潤＝陽面資3增項，負債＝減項；高層加班＝超額「轉陰為陽」，上班時間辦私事＝「轉陽為陰」；有形資源的陰陽比率是**風險控管**的關心事項。

## 七、編碼簡例：用矩陣翻譯日常管理道理（頁47-51）

作者先用 16 條「簡單道理」示範編碼（節錄）：
1. 上級要求的目標指導經理人決策：**目4** 經 **決4** 決定 **目5**，進而要求 **決5**。
2. 經理人決策受自己價值觀影響：**決5** 受 **陰面目5** 影響。
3. 授權＝上級把本該自己做的決策讓給部屬：**決5** 內容轉移到 **決6**。
4. 目標訂得高就須給足資源：對 **陽面目6** 要求高，**陽面資3/資5→資6** 須配合。
5. 基層更在乎報酬而非機構使命：**陽面目3** 對 **決6** 的影響，遠不如能否增加其 **陰面資6**。
6. 產品合客戶需要才成交：**流3** 完成的 **資3**（成品）要合 **目2**，客戶才以 **資2** 來交換。
10. **貪污**＝把組織的 **陽面資3-6**，經 **陰面流4-6** 自行轉為 **陰面資4-6**。
11. **廣告**＝投入 **資3** 做廣告（一種 **決3**）→ 影響顧客認知 **環2** → 期望其採取有利的 **決2**（採購）。
12. 老師傅手藝被自動化取代＝陰陽兩面的 **能6** 被新的 **陽面資6** 取代。
14. 長官不盡力，部屬看到（**陰面環6**）→ 影響其 **陰面目6** 對工作的重視 → **陰面決6** 也不認真 → 拖累 **陽面目6** 達成。
16. 簽核太慢失去時效：**決6** 須經 **決5.8、決5.6、決5、決4** 層層核准，故失時效，影響 **目6** 達成。

> 結論（頁53）：嚴謹、周延、互斥的架構提高思考與說明的深度廣度；由欄位構成的「因果關係網／考慮因素網」比一般流程圖更好用，能整合並累積多元而略複雜的觀念。

### 一則完整範例：例一議題1 — 中階管理者（5）決策時的考慮因素（頁81-82）

**(A) 文字解說**：①上級交辦的目標 ②自己的目標/價值觀 ③能力（知能與體力）④資源（設備/預算）⑤自己的職掌範圍 ⑥達標對自己有何好處 ⑦從若干方案中選擇 ⑧對以上各項的認知/相信程度。

**(B) 管理矩陣編碼**：
- 上級交辦目標＝依 **目3 / 目4** 交辦的 **目5**
- 自己的目標價值觀＝**陰面目5**
- 能力＝**能5**，或把 **陰面能5** 轉為 **陽面能5** 匯入 **陽面流5**
- 資源＝**資5**（含從 **陽面資3/資4** 取得者）
- 職掌範圍＝從上級 **流4** 分到自己責任區的 **流5**
- 好處＝上級承諾（影響 **環5** 的 **決4**）達標後增加的 **陰面資5**
- 方案選擇＝對各種可能 **決5** 的更高層次 **決5**（亦是 **能5** 的發揮）
- 認知/相信程度＝**環5**（資5夠嗎？能5做得來嗎？真有獎勵嗎？）

> 同類做法也用於「最高領導人（4）的決策」（頁83-84，把股東客戶＝目2、競爭者＝決2/能2/資2、政府改變＝決1、科技趨勢＝能1、自身風險偏好＝陰面目4）、以及「決策權從集權到分權」（頁85-86，CEO 的決4 整合各層級的環5/能5/目5，溝通商討屬陰陽兩面的流4/流5）。

## 九、結語與核心重點（頁221）

- 全書從管理的核心意義出發，系統發展出管理矩陣，並以 **70 則實例**展現實用價值。
- 72 欄內容應屬周延互斥，但「定義未必精準，尚在力求完善中」。
- 例題的用意**不在介紹管理方法或道理**，而在說明管理矩陣是「**合乎邏輯而且十分有用的思維架構**」——熟悉後能協助學習、整合、記憶各種因果關係，提升觀念能力。
- 任何更標準、更深入的說明，也都能用管理矩陣編碼系統來解析。作者因此「**不再提供習題**」（職場與學理處處是習題）。
- **最終建議**：把 72 欄記在腦中，做為分析問題、思考道理、觀察現象的觀念架構，「**時時在觀照中**」，很快就能體會它對思維廣度與效率的作用。
